KRATOS OS 

A standalone GNU/Linux distribution built from upstream sources 

Goals:
- No dependency on another Linux distribution
- Reproducible builds
- Source-based bootstrap
- Custom package manager
- Custom build system
- Linux kernel
- GNU userspace
- Minimal external dependencies

Build stages
------------

1. Bootstrap toolchain
2. Linux kernel
3. Base userspace
4. Init system
5. Root filesystem
6. Bootable image
7. Package manager
8. Package repository
9. Installer
10. Graphical environment
